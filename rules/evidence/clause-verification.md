# 条文核查报告 —— dsh-export-ctl-check：《出口管制法》全文核对

- **核查日期**：2026-10-07
- **核查方法**：取得**商务部官网**全文，逐条比对规则 `basis`。
- **结论**：**《中华人民共和国出口管制法》全文取得**（五章四十九条）。
  ⚠️ **最重要的收获不是"补上了条号"，而是第四条为这个插件最要紧的能力边界提供了逐字依据** ——
  见第二节。

  监督管理；法律责任；附则）。

## 二、⚠️ 本轮**最重要的发现**：第四条为插件的能力边界提供了逐字依据

`dsh-export-ctl-check` 的 README 与规则库头部一直声明一条关键能力边界：

> 「本插件**不持有管制清单**，因此**发现不了"未申报的管制物项"**。」

此前这条边界的表述方式是"因为清单本次未取得"（一个**取用状态**的理由）。
**第四条把这条边界变成了条文本身的制度设计**：

> **第四条**　国家实行**统一的出口管制制度**，通过制定**管制清单、名录或者目录**（以下统称管制清单）、
> **实施出口许可**等方式进行管理。

⇒ 逐字核对后可以这样写（**已写入规则库头部与 README**）：

- **管制清单由"国家"制定**（第九条进一步规定由**国家出口管制管理部门**制定、调整**并及时公布**）；
- **是否属于管制物项，只能对照该清单判断** —— 清单是**国家层面动态发布**的文件（第九条并规定
  **临时管制**及其**不超过二年**的期限），**不是任何企业插件可以内置的静态数据**；
- 因此"本插件不持有清单"**不是偷懒，而是这一制度的固有属性**：
  **一个内置了清单副本的插件会在清单调整后立即过期并给出错误结论**。

⚠️ **这一点还顺带解释了为什么本插件不该做"是否属于管制物项"的判断**：
第九条明确清单**会被调整**、并存在**临时管制**（须公告、期限不超过二年、期满评估），
⇒ **任何离线副本都注定过期**。

## 三、逐条核对结果（本插件引用的条文）

| 主题 | 条号 | 条文要点（逐字） |
|---|---|---|
| 出口许可制度 | **第十二条** | 「国家对管制物项的出口**实行许可制度**。出口管制清单所列管制物项或者临时管制物项，出口经营者应当向国家出口管制管理部门**申请许可**。」 |
| **最终用户与最终用途证明文件** | **第十五条** | 「出口经营者应当向国家出口管制管理部门提交管制物项的**最终用户和最终用途证明文件**，有关证明文件由**最终用户或者最终用户所在国家和地区政府机构出具**。」 |
| **最终用户的承诺义务** | **第十六条** | 「管制物项的最终用户应当承诺，**未经国家出口管制管理部门允许，不得擅自改变相关管制物项的最终用途或者向任何第三方转让**。出口经营者、进口商发现最终用户或者最终用途**有可能改变的，应当按照规定立即报告**。」 |
| 最终用户与最终用途风险管理 | **第十七条** | 「国家出口管制管理部门建立管制物项最终用户和最终用途**风险管理制度**，对……进行**评估、核查**。」 |
| **管控名单** | **第十八条** | 对三类情形的进口商和最终用户建立**管控名单**；「出口经营者**不得违反规定与列入管控名单的进口商、最终用户进行交易**」；确需交易的可以向管理部门提出申请；符合条件的可以申请移出。 |
| 报关时交验许可证件 | **第十九条** | 「出口货物的发货人或者代理报关企业出口管制货物时，应当**向海关交验**由国家出口管制管理部门颁发的**许可证件**，并按照国家有关规定办理报关手续。」该条并规定海关提出质疑、组织鉴别期间**不予放行**。 |
| 禁止为违法行为提供服务 | **第二十条** | 「任何组织和个人**不得为出口经营者从事出口管制违法行为提供代理、货运、寄递、报关、第三方电子商务交易平台和金融等服务**。」 |
| 出口经营资格 | **第十一条** | 「出口经营者从事管制物项出口，应当遵守本法和有关法律、行政法规的规定；**依法需要取得相关管制物项出口经营资格的，应当取得相应的资格**。」 |

## 四、本报告**没有**改动的东西（与 `dsh-bid-ca-precheck` 同一纪律）

1. **`kind` 未提高**：本插件核对的是**企业内部台账的齐备与自洽**，本法规范的是**出口经营者与管理部门的行为**。
   "台账某栏空着"与"未经许可擅自出口"**不是同一命题**。
2. **`severity` 未改动**：`dsh-export-ctl-check` 的规则库中，**没有一条是 `error`**（与 README 的边界声明一致）；
   取得条文不构成把它变成 error 的理由。
3. **`excerpt` 未改动**：本报告核对的是**条号与主题的相符性**，**未逐字核对每条 `excerpt`**；
   把 `excerpt` 换成条文原句需要逐条对照后再做，否则等于声称"原文已抄录"。
